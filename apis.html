Markets API

The API behind Markets by MP: search 12,000+ US and Canadian stocks and ETFs, crypto and currencies, then get quotes, daily history, statistics, dividends, dips and market overviews. The Markets website and the desktop app use exactly these routes.

Live numbers appear here once the API is published.

curl https://markets.marcantoniopovolo.com/api/v1/assets/xtse.ry/quote
  • GET/assets/search?q=shopifyFind stocks, ETFs, crypto and currencies by name, ticker or nickname
  • GET/assets/{id}/quoteLatest price and today’s change
  • GET/quotes?ids=xtse.ry,xnas.aaplUp to 50 quotes in one call
  • GET/assets/{id}/history?range=1YDaily prices, raw and adjusted
  • GET/assets/{id}/dip?windowDays=30How far an asset is below its recent high
  • GET/markets/overviewBenchmarks and the day’s biggest moves
  • GET/fx?from=USD&to=CADExchange rates (European Central Bank)
  • GET/statsDownloads and API calls, as shown on this page
Read the API referenceOpenAPI specSource code

No key needed

Free to call.

Public market data is keyless: 120 requests a minute per address, more when signed in. Errors and limits are plain JSON.

Honest data

Every value says where it came from.

Each response names its source and time. Hosted stock prices are labelled demo data until a licensed feed is connected; exchange rates are real.

Run your own

Or take it with you.

The Markets desktop app for Mac and Windows runs the whole API on your own computer, with real prices and no key.
