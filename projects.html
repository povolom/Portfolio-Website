02 / PERSONAL PROJECT · INVESTING APP

Portfolio Lab

Portfolio Lab tracks TSX and US holdings in Canadian dollars. It pulls delayed live quotes and the USD/CAD rate, charts the last 100 trading days, and shows day change, unrealized gain and allocation. Holdings and API keys stay in the visitor’s own browser, and anyone without a key sees a demo portfolio.

It started as a local Python and SQLite app and became a static web app on GitHub Pages. It’s AI-assisted, and I use it to practise reading, testing and extending a complete product, from the maths module and its tests to caching around a 25-request daily API limit.
