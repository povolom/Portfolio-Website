Built, not public yet01 / INVESTING

Markets by MP

Markets shows my TSX and US stocks together, in Canadian dollars: live US prices, today’s change, total return, allocation and a chart of the whole portfolio. It installs on a phone or computer like a regular app, walks new users through getting a free data key, and keeps keys and holdings in the browser. Visitors without a key see a demo portfolio. It’s built, and I’m testing it before opening it up.

It started as a local Python and SQLite app, became a web app called Investing Tracker, and is now Markets by MP. I decide what it should do, use AI coding tools to write the code faster, then review, test and fix each change. It’s how I practise reading, testing and extending a complete product, from the tested maths module to working within free data limits: US prices from Finnhub, Toronto prices from Alpha Vantage.
